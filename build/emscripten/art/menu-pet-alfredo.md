# Alfredo menu sprite

`menu-pet-alfredo.png` is a transparent RGBA preparation of the Alfredo reference
attached to the character request. The image tool removed the white background
and ground shadow while retaining the seated orange tabby, green eyes, red
patterned bandana, tail and paws. No existing pet asset was replaced.

The complete sprite is rendered on the shared menu canvas, with the established
breathing and time-of-day lighting. It deliberately has no independently cut
paws or tail, avoiding holes at animation seams. The in-game character is a
separate volumetric articulated model using the existing garden primitives.
